# 实时削峰平滑（C）

每个采样点都是现场拿到的：来一个立刻出一个（O(1)，不看未来）。门控决定跟不跟，跟随器用带**目标速度前馈**的 min-jerk 画成圆滑曲线，尽量贴着实时数据走。

## 算法思路

滞后主要不是门控（大跳变 2 点就确认），而是上一版跟随器每次都规划「停在当前目标」。目标还在动时，规划一直在刹车，所以会落后 50～70 个点。

这一版分成两层：

### 1. 双边门控（跟不跟）——不变

死区内的周期齿不跟；中等偏离要持续 `hold` 点；大跳变连续 2 点确认。确认后粘滞跟踪，窗口像平台再锁死。门控输出 `dest`，不是直接当曲线。

### 2. 带速度前馈的 min-jerk（怎么走）——降滞后

估计目标速度，规划终点不再是静止：

```
dest_vel  ← EMA(Δdest)          // 目标正在往哪走
T         = t_min + t_sqrt * √|dest − y|
(y, v, a) ← 五次多项式 1 步走到 (dest, dest_vel, 0)
a         ← 限加加速度 j_max    // 开头仍是缓加速，没有单点陡跳
```

- `dest_vel`：斜坡上跟着走，不再每次都规划刹停  
- `T` 随误差开方变长：大台阶仍能圆角，小齿（误差小）`T` 有下限，平台不会跟着晃  
- 仍然是每点实时进出，没有未来窗口  

## 参数

- `--radius`（默认 16）：中等偏离确认长度，应大于最宽周期齿。
- `--sigma`（默认 5）：越大 `T / j_max` 越保守，更圆、略慢。

## 实时嵌入

```c
#include "smooth.h"

PeakCutStream s;
peakcut_stream_init(&s, 16, 5.0f);

float y = peakcut_stream_update(&s, x);
```
