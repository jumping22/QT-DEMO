# 实时削峰平滑（C）

每来一个采样立刻输出一个点（O(1)，不看未来）。输出点连起来是一条**圆滑、无尖峰**的曲线；周期锯齿平台会被压成近乎直线，真下落仍能在几个点内跟上。

## 算法优化思路

上一版只挡**向上**的短脉冲，下落沿一律放行。A/B 这类数据的平台并不是静音，而是周期齿：

- A：约 16 点一个齿，峰谷差约 5–7
- B：约 64 点一个齿，峰谷差约 8–16，半齿可长达 30+ 点

齿的**下落沿**被当成真跌落，输出就贴着下包络晃；B 的半齿又长过旧的 `hold=7`，上升沿还会被确认成真变化。三极点在门控目标来回跳时，增益突变还会留下折角。

所以这一版改了两处，都仍然是因果、每点一个输出。

### 1. 双边死区 + 持续时间门控（先决定「跟不跟」）

相对当前输出 `y`：

| 情况 | 目标 `gated` |
|---|---|
| `|x − y| ≤ dead`（默认约 6） | 几乎不动，只漏 1.2% 去跟慢漂移 |
| 偏离不足 `hold` 点（默认 16） | 仍视为齿，目标几乎不动 |
| 向上偏离 ≥ `big_up`（约 13）或向下 ≥ `big_dn`（约 10），且已连续 **2** 点 | 当真跳变，目标改成 `x` |
| 中等偏离持续满 `hold` 点 | 当真斜坡，目标改成 `x` |

单点尖峰过不了「2 点确认」，不会把曲线拽走。真跌落第一步通常就超过 `big_dn`，等 2 点就跟，不必再排 16 点的队。`hold` 只要大于最长周期齿在死区外的停留，平台上的目标就是一条几乎不变的线。

确认之后进入**粘滞跟随**：目标一直等于 `x`，直到最近窗口的峰谷差小于约 7 且已经贴住 `y`，才重新锁回平台。斜坡因此是连续跟上的，不会「积误差 → 猛追 → 再锁死」形成台阶。

### 2. 临界阻尼 SmoothDamp（再把折线收圆）

门控目标在平台上几乎恒定，在边沿才切到 `x`。若用可变 `α` 的多级 EMA，`α` 一跳，速度不连续，连线会有折角。这里改成带速度状态的临界阻尼跟随（Unity SmoothDamp）：

```
omega = 2 / smoothTime
y, vel  →  以临界阻尼方式靠近 gated
```

`smoothTime` 随 `|gated − y|` 变：平台上约 16（很圆、相邻点几乎共线），大误差时约 1.5，下落再乘 0.42。因为速度是状态，目标切换时曲线仍是 C1 的。

## 参数

- `--radius`（默认 16）：中等偏离要持续多少点才算真斜坡。应大于数据里最宽的周期齿。大跳变仍走 2 点确认，所以加长 radius 主要不影响真跌落。
- `--sigma`（默认 5）：越大死区略增、`smoothTime` 越大，平台越平。下落仍走短 `smoothTime`。

## 实时嵌入

```c
#include "smooth.h"

PeakCutStream s;
peakcut_stream_init(&s, 16, 5.0f);

float y = peakcut_stream_update(&s, x);
```

## 命令行

```bash
make
./smooth
./smooth --sigma 6            # 平台更圆
./smooth --live --csv
./smooth --offline            # 整段批处理对照
./smooth --self-test
```
