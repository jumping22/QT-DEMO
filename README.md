# 实时削峰平滑（C）

每来一个采样立刻输出一个点（O(1)，不看未来）。输出点连起来是一条**圆滑、无尖峰**的曲线；平台段会压得很平，真下落仍能在几个点内跟上。

## 算法思路

整条链路只有两级，都是因果的。

### 1. 持续时间门控（削峰，几乎不平滑）

尖峰和真变化的差别不在幅度，而在**朝向和能持续多久**：

- 相对当前输出 **向上** 冲、持续不到 `hold` 个点 → 当成尖峰，目标几乎不动  
- 向上冲且持续满 `hold` 点 → 当真上升，目标改成当前值  
- **向下** 走 → 目标立刻等于当前值（真跌落不排队）  

门控不搬窗口，只记一个向上计数。所以削 8 点宽的周期峰，不必再等 17 点滑窗，下落也不会被窗口里的旧高点拖住。

未确认的上冲带一点泄漏（约 8%），避免长斜坡冻住再突然跳。

### 2. 自适应三极点低通（把折线收成圆滑曲线）

门控之后的目标在平台上几乎不变，在边沿会跳。直接输出会有折角，所以用三级一阶低通串起来：

```
z1 += a * (gated - z1)
z2 += a * (z1  - z2)
z3 += a * (z2  - z3)   → 这就是输出 y
```

三极点比单极点更圆（二阶差分小），但若 `a` 固定很小，下落又会变钝。所以 `a` 随 **|gated − y|** 变：

```
mix = |err| / (|err| + knee)     // 平台 ≈ 0，大跳变 ≈ 1
a   = amin + (amax − amin) * mix
下落时 a 再乘 1.18
```

- 平台：误差小 → `a ≈ amin`（默认约 0.04）→ 相邻输出几乎贴在一条线上  
- 真下落：误差大 → `a ≈ amax`（默认约 0.65）→ 几个点内跟上，不回到 20 点级延迟  

这是「该平的时候很平，该动的时候给路」的变带宽滤波，不是简单加大窗口。

### 参数

- `--radius`（默认 7）：向上持续多少点才认作真上升。更大削更宽的峰，真上升会多等几拍。  
- `--sigma`（默认 5）：越大 `amin` 越小，平台越圆。下落仍走 `amax`，所以加 sigma 主要不影响跌落实时性。

## 实时嵌入

```c
#include "smooth.h"

PeakCutStream s;
peakcut_stream_init(&s, 7, 5.0f);

float y = peakcut_stream_update(&s, x);
```

## 命令行

```bash
make
./smooth
./smooth --sigma 6            # 平台更圆
./smooth --live --csv
./smooth --offline            # 整段批处理对照
./smooth --self-test
```
