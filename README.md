# 实时削峰平滑（C）

每来一个采样立刻输出一个点（O(1)，不看未来）。输出点连起来是一条**圆滑 S 形**曲线：平台无尖峰，升降没有直线陡段、也没有单点跳变。

## 算法优化思路

上一版在误差大时用 `vmax` 把每步增量封死（约 0.50）。于是连续几十上百个点的 `Δy` 完全相同——图上看就是一段斜直线，不是平滑上升。

限速本身就会制造匀速段。这一版**不再用速度上限去走路**，改为每一步重规划一条五次最小加加速度轨迹（min-jerk）：

### 1. 双边死区 + 持续时间门控（跟不跟）

和上一版相同：死区内的周期齿不跟；大跳变连续 2 点才确认；确认后粘滞跟随，直到窗口已经像平台再锁死。门控只决定目标，不决定走多快。

### 2. 在线 min-jerk（怎么走）

从当前状态 `(y, v, a)` 规划到 `(目标, 0, 0)`，每步只执行 1 个采样：

```
T  = t_min + t_kv * |v|          // 走得越快，预留越长的刹停时间
y, v, a  ← 五次多项式走 1 步
```

- 速度是钟形，不是梯形：中间不会出现恒定 `Δy` 的斜直线  
- `T` 随 `|v|` 变长，一旦快要匀速，规划会提前减速，斜率继续变化  
- 没有 `vmax` 裁剪，所以不会出现一排等间距的陡升/陡降点  

## 参数

- `--radius`（默认 16）：中等偏离要持续多少点才算真斜坡。应大于最宽周期齿。大跳变仍走 2 点确认。
- `--sigma`（默认 5）：越大 `T` 越长，升降越圆、峰值斜率越低。

## 实时嵌入

```c
#include "smooth.h"

PeakCutStream s;
peakcut_stream_init(&s, 16, 5.0f);

float y = peakcut_stream_update(&s, x);
```
