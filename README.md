# RK3568 UART 自环测试

在 RK3568 上对 `/dev/ttyS9` 做自环收发测试（TX 直接回到 RX）：按可配置间隔发送可配置长度的数据包（含时间戳），同时组帧校验接收数据，退出时统计丢包率。收发内容分别写入日志文件。

## 编译

在板子上直接编译：

```bash
make
```

交叉编译（主机需有 aarch64 工具链）：

```bash
make CROSS_COMPILE=aarch64-linux-gnu-
```

## 运行

硬件上将 TX/RX 短接（或外部环回）后：

```bash
# 默认: /dev/ttyS9, 115200, 250 字节/包, 间隔 100ms
./uart_loop_test

# 自定义包长与发送间隔
./uart_loop_test -s 512 -i 50

# 完整参数示例
./uart_loop_test -d /dev/ttyS9 -b 115200 -s 250 -i 100 \
  -t /tmp/uart_tx.log -r /tmp/uart_rx.log -n 100
```

| 参数 | 含义 | 默认 |
|------|------|------|
| `-d` | 串口设备 | `/dev/ttyS9` |
| `-b` | 波特率 | `115200` |
| `-s` | 单包字节数 | `250`（最小约 25，最大 8192） |
| `-i` | 发送间隔（毫秒） | `100` |
| `-t` / `-r` | TX/RX 日志 | `/tmp/uart_tx.log` / `/tmp/uart_rx.log` |
| `-n` | 发送包数后退出（0 一直发） | `0` |

需要串口设备访问权限（root 或加入 `dialout` 组）。Ctrl+C 停止；退出前会再等约 500ms 收完尾包，然后打印丢包统计。有丢包或坏帧时进程退出码为 2。启动时应看到版本 `1.2.0-loopback`。

## 发包格式

| 偏移 | 长度 | 内容 |
|------|------|------|
| 0 | 2 | Magic `0x55 0xAA` |
| 2 | 4 | 序列号（小端） |
| 6 | 8 | `tv_sec`（墙钟秒） |
| 14 | 8 | `tv_nsec`（墙钟纳秒） |
| 22 | 2 | payload 长度 |
| 24 | N-24 | 填充模式数据（N 由 `-s` 指定） |

接收侧按 Magic 组帧，校验 header/payload；日志为文本，含 seq 与完整 hex。
